Guía para configurar NGINX en Windows con subdominios personalizados

  1. Ubica tu archivo nginx.conf
    Debe estar junto a tu archivo docker-compose.yml. Contendrá algo como: 
    http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile        on;
    keepalive_timeout  65;

    server {
        listen       80;
        server_name  localhost;

        set $subdomain "";
        if ($host ~* ^(?<sub>.+?)\.(dev|staging|prod)\.miapp\.com$) {
            set $subdomain $sub;
            set $env $2;
        }

        location / {
            proxy_pass http://odoo_$subdomain_$env:8069;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
}
  2. Configura docker-compose.yml
    Asegúrate de tener algo como esto: 
    version: '3.8'

services:
  nginx-proxy:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: nginx-proxy-odoo
    ports:
      - "80:80"
    networks:
      - odoo_network
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    restart: always

networks:
  odoo_network:
    external: true
  3. Agrega las entradas al archivo hosts en Windows
    Edita C:\Windows\System32\drivers\etc\hosts como administrador. Añade: 
    127.0.0.1 test.dev.miapp.com
127.0.0.1 staging.miapp.com
127.0.0.1 prod.miapp.com
  4. Ejecuta el contenedor NGINX
    En PowerShell: 
    docker compose up -d
  5. Asegúrate de que tus contenedores Odoo estén conectados a odoo_network
    Puedes forzar la conexión si hace falta: 
    docker network connect odoo_network odoo_test_dev
  6. Accede a la instancia
    Abre en tu navegador: 
    http://test.dev.miapp.com
